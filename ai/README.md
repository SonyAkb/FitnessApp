# AI-модуль (Модуль 6) — заготовка

Здесь должен появиться Google Colab ноутбук с обучением лёгкой модели
(рекомендация следующей тренировки/нагрузки на основе истории пользователя).

## Как это встроить в проект

1. Обучите модель в Colab, экспортируйте (`pickle`/`joblib`).
2. Положите файл модели в `backend/app/modules/ai_watch/model/`.
3. Замените `rule_based_recommend(...)` в
   `backend/app/modules/ai_watch/ai_recommender.py` на инференс модели.

Подробности и альтернативный вариант (инференс прямо из Colab через ngrok) —
см. `docs/PLAN.md`, раздел 5.

## Пока что

Backend уже работает с rule-based заглушкой (`GET /ai/recommend`) —
можно демонстрировать MVP уже сейчас, не дожидаясь готовой модели.
