# MoSCoW Analysis — FitQuest MVP

> **Горизонт:** первая работоспособная версия (MVP) — к **01.12.2026**; до 25.12.2026 — доработки и документация. Требования FR/NFR и границы MVP — [`REQUIREMENTS.md`](REQUIREMENTS.md).

---

## Принципы распределения

| Категория | Описание | Критерий для FitQuest |
|-----------|----------|----------------------|
| **MUST** | Обязательно для MVP | Без этого демо-сценарий **не работает** |
| **SHOULD** | Желательно для MVP | Демо работает, но без части фич «неполное» |
| **COULD** | Желательно, но не критично | Улучшает UX, но не блокирует демонстрацию |
| **WON'T** | Откладывается на будущее | Не входит в семестровый срок |

---

## MUST — Обязательно для MVP

| # | Функционал | Модуль | Обоснование |
|---|------------|--------|-------------|
| M1 | Регистрация и вход | Auth | Без аутентификации — нет пользователя, нет дальнейшего потока |
| M2 | Создание цели и профиля | Profile | Требуется для персонализации тренировок и питомца |
| M3 | Создание и редактирование планов тренировок | Workouts | Без планов — нет «сегодняшней тренировки» |
| M4 | Запись в расписание (CALENDAR) | Schedule | Без расписания — нет автоматической подстановки плана |
| M5 | Выполнение тренировки (таймер + чек-лист) | Workouts | Сердце MVP — пользователь тренируется |
| M6 | Завершение тренировки и запись в историю | Workouts | Базовая функция: фиксация выполнения |
| M7 | Начисление XP и обновление питомца | Pet | Gamification — главная фишка проекта |
| M8 | Уровни питомца и реакция на действия | Pet | Визуальная обратная связь за усилия |
| M9 | Дашборд со сводкой за неделю | Dashboard | Показывает прогресс без глубокого анализа |
| M10 | Уведомления о событиях | Notifications | Информирование пользователя о результатах |
| M11 | Телеметрия от симулятора (шаги/пульс) | Devices/Simulator | Демонстрация интеграции «устройств» без Raspberry Pi |
| M12 | Модульная архитектура (5 независимых модулей) | Core | Главная цель проекта — показать модульность |


---

## SHOULD — Желательно для MVP

| # | Функционал | Модуль | Обоснование |
|---|------------|--------|-------------|
| S1 | История тренировок (детальный список) | Workouts | Пользователь хочет видеть историю, но демо проходит без неё |
| S2 | Симуляция пропуска слота (missed) | Schedule | Показывает реакцию на пропуски, но не обязательна |
| S3 | Улучшенное настроение питомца (разные эмоции) | Pet | Улучшает UX, но базовое `happy`/`idle` достаточно |
| S4 | Стриск (серия дней) | Pet | Показывает долгосрочную мотивацию, но без него MVP работает |
| S5 | Подробная статистика в дашборде | Dashboard | Полезно, но базовая сводка уже есть |
| S6 | Mock-платежи (Pro-подписка) | Subscription | Демонстрирует monetization, но не критично для core flow |
| S7 | AI-рекомендации (rule-based) | AI | Показывает «умные» функции, но MVP работает без них |


---

## COULD — Желательно, но не критично

| # | Функционал | Модуль | Обоснование |
|---|------------|--------|-------------|
| C1 | Долгосрочная история телеметрии | Devices | Полезно для анализа, но не обязательна |
| C2 | Просмотр прошлых слотов в календаре | Schedule | Удобство, но не блокирует основной поток |
| C3 | Повторяющиеся тренировки (RRULE) | Schedule | Хорошая фича, но можно обойтись без неё в MVP |
| C4 | Персонализация рекомендаций AI (обученная модель) | AI | Улучшает качество, но rule-based заглушка работает |
| C5 | Виджет питомца на главном экране Android | Android | Удобство, но не критично для демонстрации |


---

## WON'T — Откладывается на будущее

| # | Функционал | Модуль | Обоснование |
|---|------------|--------|-------------|
| W1 | Raspberry Pi (реальные датчики) | Devices | Требует оборудования и GPIO |
| W2 | Push-уведомления (Firebase/APNs) | Notifications | Требует настройки push-сервисов — достаточно центра в приложении |
| W3 | Многоязычность (i18n) | Core | Улучшает UX, но не критично для учебного проекта |
| W4 | Темная тема | Android | Декоративная функция, MVP может быть в одном стиле |
| W5 | Multiplayer/соревнования | Pet | Выходит за рамки MVP |
| W6 | Экспорт данных (PDF/CSV) | Dashboard | Удобство, но не обязательное |
