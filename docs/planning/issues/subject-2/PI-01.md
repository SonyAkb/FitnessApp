## Что сделать
Создать `pi-fit-baddy/device/` по структуре `docs/pi.md` §2 с единственной точкой ветвления mock/real.

## Детали / спецификация
- `device/config.py` — все параметры из окружения (`SENSOR_MODE=mock`, `I2C_BUS=1`, адреса, пороги, `PUBLISH_*`, `CALORIES_PER_STEP=0.04`).
- `device/clock.py` — `Clock.now()`, `MonotonicClock`, `ManualClock` для тестов.
- `device/bus/factory.py` — `create_bus(config)`: `real` → ленивый `import smbus2`; `mock` → `FakeSMBus`.
- `device/bus/fake_smbus.py` — `write_byte_data`, `read_byte_data`, `read_i2c_block_data`; маршрутизация по адресу на виртуальные чипы; неизвестный адрес → `OSError(121, "Remote I/O error")`.
- `requirements.txt` (без smbus2), `requirements-pi.txt` (smbus2, gpiozero).

## Критерии готовности
- [ ] `SENSOR_MODE=mock pytest` проходит на Mac без smbus2
- [ ] В drivers/services нет проверок режима
- [ ] CI-job `pi` включается
