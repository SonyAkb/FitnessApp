## Что сделать
Сейчас WS сам создаёт синтетику, поэтому данные Pi в него не попадут (П-17).

## Детали / спецификация
- Сделано: WS раз в `TELEMETRY_WS_INTERVAL_SECONDS` забирает новые точки пользователя из БД (`id >` последней отправленной) и рассылает их; при подключении сначала шлёт последнюю точку. Опрос БД вместо in-memory менеджера — без передачи событий из синхронных обработчиков в цикл событий и с поддержкой нескольких процессов.
- Автосимуляция для демо — только если у пользователя нет реальных устройств (`raspberry_pi`, `health_connect`); отдельный флаг не нужен.

## Критерии готовности
- [x] Тест: точка из ingest приходит в открытый WS
- [x] Без автосимуляции WS молчит, пока нет точек
