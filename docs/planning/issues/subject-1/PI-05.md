## Что сделать
Драйверы, работающие с любой шиной того же интерфейса.

## Детали / спецификация
- `device/drivers/mpu6050.py`: проверка WHO_AM_I, пробуждение, установка диапазона, чтение ускорения в g.
- `device/drivers/max30102.py`: инициализация режима и частоты, чтение и разбор FIFO.
- Тест переносимости: подмена шины объектом-шпионом с тем же интерфейсом — драйверы работают без изменений.

## Критерии готовности
- [ ] Тесты драйверов из `docs/pi.md` §8
- [ ] Неверный адрес → ошибка
