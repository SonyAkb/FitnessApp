## Что сделать
Разворачивать `repeat_rule` в вхождения при чтении расписания за период.

## Детали / спецификация
- Поддерживаемый формат MVP: `FREQ=DAILY` и `FREQ=WEEKLY;BYDAY=MO,WE,FR` (+ необязательный `UNTIL`).
- `GET /schedule?from&to` возвращает вхождения с полем `occurrence_date`; пропуск/завершение вхождения создаёт отдельную запись-исключение.
- Валидация правила → 422 для неподдерживаемого.

## Критерии готовности
- [ ] Тесты: недельное правило за 2 недели даёт верные даты
- [ ] Пропуск одного вхождения не трогает остальные
