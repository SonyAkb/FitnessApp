## Что сделать
Перенос будущей тренировки на другое время; пересечение с другой тренировкой → 409 (D-15).

## Детали / спецификация
- `PATCH /schedule/{id}` с новым `starts_at`: прошлое → 422, слот уже прошёл → 409, пересечение интервалов `[starts_at, ends_at)` (по умолчанию 60 мин) → `409 {detail, conflict_id}`.
- Уведомление «Тренировка перенесена».

## Критерии готовности
- [ ] Тесты на конфликт и успешный перенос
- [ ] Уведомление создаётся
