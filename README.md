# FitQuest — фитнес-трекер с игровым персонажем 🦊

> Иммерсивное приложение для планирования тренировок и отслеживания собственного прогресса с «прокачкой» виртуального питомца через реальную физическую активность.

## Функционал FitQuest

- создание планов (программ) тренировок и расписания;
- просмотр информации по тренировкам (таймер, чек-лист упражнений, история тренировок);
- получение уведомлений-напоминаний (плановые, мотивационные);
- отслеживание прогресса и статистики тренировок на дашбордах;
- оформление платной подписки (тестовый режим платёжной системы);
- развитие виртуального персонажа  — он растёт/радуется, если пользователь достигает целей тренировок, и «грустит»/деградирует при пропусках;
- получение простых ИИ-рекомендаций (лёгкая модель, обучена на Google Colab);
- «подключение умных часов» (эмулятор, генерирующий синтетические данные (шаги, пульс)).

Данные об активности (пульс, шаги) приложение получает через единый API. Источник данных зависит от режима:

- **Тестовый режим** — данные синтетические, генерируются эмулятором.
- **Боевой режим** — данные снимаются с реального устройства: акселерометр и пульсометр на Raspberry Pi.

Клиентская часть — нативное Android-приложение на Java — не знает, откуда пришли данные, она работает с одним и тем же контрактом в обоих случаях.

## Архитектура

```
┌─────────────┐        ┌──────────────┐        ┌────────────────────┐
│   Android   │───────▶│  REST/WS API │───────▶│  Источник данных   │
│  (Java)     │        │              │        │                    │
└─────────────┘        └──────────────┘        │  тест: эмулятор    │
                                               │  боевой: RPi + I2C │
                                               └────────────────────┘
```

---

### Тестовый режим

Эмулятор — обычный сервис на FastAPI, который раз в N секунд генерирует правдоподобные значения пульса и шагов и отдаёт их по тем же путям. Не требует железа, поднимается локально, подходит для разработки и демо.

### Боевой режим

Тот же API, но за ним — Raspberry Pi:

- **Пульс** — датчик MAX30102 (I2C) или аналог.
- **Шаги** — акселерометр MPU6050 (I2C), подсчёт по пикам ускорения.

GPIO/I2C-логика инкапсулирована на стороне Pi и наружу отдаёт данные в том же формате, что и эмулятор. Никакой специфики устройства не просачивается выше уровня API.

## Модули 

### Модуль 1 — Личный кабинет (пользователи, аутентификация и расписания)
- Регистрация/вход, роли (пользователь/админ), профиль (цели, вес, уровень).
- Календарь/расписание тренировок (создание, перенос, повторяющиеся события).

### Модуль 2 — Тренировочный модуль (планы тренировок)
- Создание программ тренировок (набор упражнений, подходы/повторы/вес).
- Экран «выполнения» тренировки: таймер отдыха, чек-лист, фиксация факта выполнения.
- История тренировок пользователя.
  
### Модуль 3 — Игровой персонаж 
- Виртуальный питомец/персонаж, у которого есть параметры (энергия, настроение, уровень).
- Начисление «очков» за выполненные тренировки/цели, деградация при пропусках.
- Достижения/квесты («тренируйся 3 дня подряд» и т.п.).

### Модуль 4 — Подписка
- Тарифы (free/pro), оформление подписки через тестовый режим платёжной системы.
- Обработка вебхуков (приход/отмена прихода, sandbox), история платежей.
- Ограничение доступа к фичам по тарифу (например, ИИ-рекомендации только на pro).

### Модуль 5 — Дашборды и уведомления
- Экран аналитики: прогресс по весам/повторениям, календарь активности, графики.
- Система уведомлений: напоминания о тренировке, поздравления, мотивация, отклик персонажа («питомец грустит») и т.п.

### Данные с устройства и ИИ-рекомендации
Приём данных через API устройства (см. выше), лёгкая ML-модель (обучается в Google Colab) для рекомендации следующей тренировки на основе истории.

- Backend: Python (FastAPI)
- БД: PostgreSQL
- Клиент: Android (Java, Android SDK)

- Тестовый режим: эмулятор на Python (FastAPI)
- Боевой режим: Raspberry Pi, Python (RPi.GPIO / smbus2, I2C)

## Пользователи и их проблемы


### 1. Новичок — «Хочу начать, но не знаю, с чего»

**Кто это:** человек, который решил заняться спортом, но до этого не имел опыта тренировок. Те, кто давно откладывает «с понедельника», а теперь наконец собрались.

**Описание:** хочет прийти в форму, но его пугает сложность: непонятно, какие упражнения делать, сколько подходов, как долго отдыхать и как не бросить через неделю. Любая ошибка воспринимается как повод всё бросить.

**Главная проблема:** страх «сделать что-то не так», отсутствие готового плана и слабая мотивация на начальных этапах, когда результат ещё не виден.

**Как решает FitQuest:**
- **ИИ-рекомендации** снимают с пользователя необходимость составлять программу тренировок: приложение само подсказывает, что делать сегодня, исходя из его уровня и целей.
- **Экран выполнения тренировки** даёт чёткую структуру — таймер отдыха, чек-лист упражнений, фиксация факта выполнения. Не нужно думать, нужно просто идти по списку.
- **Виртуальный питомец и квесты** дают быстрый эмоциональный отклик: первые маленькие достижения («сделай 3 тренировки подряд») и радость персонажа закрепляют привычку ещё до того, как появятся видимые результаты в теле.

---

### 2. Регулярный — «Занимаюсь постоянно, хочу контроля и удобства»

**Кто это:** опытный пользователь, у которого тренировки уже стали частью жизни (3–4 раза в неделю). Он знает, что делает, и ему не нужны базовые советы.

**Описание:** важны контроль, прогресс и удобство. Он ценит своё время и не хочет вручную вбивать кучу данных после каждой тренировки.

**Главная проблема:** рутина при ведении дневника тренировок, необходимость отслеживать прогрессию нагрузок (веса, повторения, объёмы) и желание видеть единую картину активности — не только в зале, но и в повседневной жизни.

**Как решает FitQuest:**
- **Автоматический сбор данных** (пульс, шаги) через единый API — пользователю не нужно вручную заполнять дневник активности, всё подтягивается само.
- **Дашборды и аналитика** дают наглядные графики прогресса по весам и календарь активности, чтобы видеть общую картину.
- **Pro-подписка** открывает расширенную аналитику и продвинутые ИИ-рекомендации для тех, кто хочет выйти на новый уровень.

---

### 3. Непостоянный — «Начинаю, срываюсь, бросаю»

**Кто это:** человек с сильной начальной мотивацией, но слабой дисциплиной. Может отзаниматься месяц, потом забить на два, а затем снова начать — и так по кругу.

**Описание:** искренне хочет заниматься, но жизнь регулярно сбивает с пути. А когда он срывается, не находит сил/мотивации опять начать 

**Главная проблема:** Отсутствие внешней ответственности и эмоциональное выгорание. Обычные трекеры просто показывают «сломанную серию дней», что только усиливает демотивацию.

**Как решает FitQues:**
- **Виртуальный питомец** — ключевая механика именно для этой аудитории. Персонаж «грустит» при пропусках, и пользователю психологически проще почувствовать ответственность *перед кем-то*, чем перед самим собой. Это мягко возвращает его к тренировкам.
- **Мотивационные уведомления** с откликом персонажа («Я скучаю, давай просто сделаем лёгкую разминку?») помогают вернуться в строй без давления.
- **Гибкость ИИ-рекомендаций**: если приложение видит, что пользователь давно не занимался, оно предложит более лёгкую тренировку, чтобы помочь мягко, а не резко, вернуться в режим.

# User Stories 

## A - Знакомство

### US-A1. Регистрация и вход
**Как** новый пользователь,  
**я хочу** зарегистрироваться и войти в аккаунт,  
**чтобы** мои тренировки и прогресс сохранялись между устройствами.

*Персона:* Новичок

### US-A2. Заполнение профиля
**Как** пользователь,  
**я хочу** указать свои цели, текущий вес и уровень подготовки,  
**чтобы** приложение могло подбирать подходящие нагрузки.

*Персона:* Новичок

---

## B - Мой план

### US-B1. Создание программы тренировок
**Как** пользователь,  
**я хочу** собрать программу из упражнений (с подходами, повторами, весом),  
**чтобы** заниматься по своему плану.

*Персона:* Регулярный, Новичок, Непостоянный

### US-B2. Расписание тренировок
**Как** пользователь,  
**я хочу** расставить тренировки по календарю и настроить повторения,  
**чтобы** не держать план в голове.

*Персона:* Регулярный, Новичок, Непостоянный

### US-B3. Перенос тренировки
**Как** пользователь,  
**я хочу** перенести запланированную тренировку на другой день, если планы изменились,  
**чтобы** не ломать расписание.

*Персона:* Непостоянный

---

### US-C1. Экран выполнения
**Как** пользователь,  
**я хочу** видеть во время тренировки таймер отдыха и чек-лист упражнений,  
**чтобы** не отвлекаться и не считать повторения в уме.

*Персона:* Регулярный, Новичок, Непостоянный

### US-C2. Фиксация выполнения
**Как** пользователь,  
**я хочу** отмечать выполненные подходы и завершать тренировку,  
**чтобы** история была актуальной.

*Персона:* Регулярный

### US-C3. История тренировок
**Как** пользователь,  
**я хочу** просматривать список прошлых тренировок,  
**чтобы** видеть, что и когда я делал.

*Персона:* Регулярный, Новичок, Непостоянный

### US-D1. Рост питомца
**Как** пользователь,  
**я хочу**, чтобы мой питомец рос и радовался после выполненных тренировок,

**чтобы** мягко мотивировать себя не забрасывать тренировки.

### US-D3. Квесты и достижения
**Как** пользователь,

# Критерии приемки

## **A - Знакомство**
### **US-A1. Регистрация и вход**
1. Регистрация нового пользователя
   - Поля: email, пароль, подтверждение пароля
   - Валидация email (формат, уникальность), пароль: мин. 8 символов, буквы и цифры
   - Отображение ошибок валидации
2. Вход в аккаунт
   - Поля: email и пароль
   - Успешный вход → переход в приложение, ошибка → «Неверный email или пароль»
   - Ссылка «Забыли пароль?»
3. Сохранение сессии
   - Автоматический вход при повторном открытии, кнопка «Выйти» в настройках
### **US-A2. Заполнение профиля**
1. Экран заполнения профиля
   - Отображается после регистрации, можно пропустить (с предупреждением), доступен через «Настройки» → «Мой профиль»
2. Поле «Цель тренировок» (обязательно)
   - Выбор одного: Снижение веса / Набор массы / Выносливость / Поддержание здоровья
3. Поле «Текущий вес»
   - Числовое значение (кг), валидация: 30-300 кг, цифровая клавиатура
4. Поле «Уровень подготовки»
   - Выбор: Новичок (<3 мес) / Средний (3-12 мес) / Продвинутый (>1 года), по умолчанию «Новичок»
5. Сохранение данных
   - Кнопка «Начать тренировки» активна при заполненных полях, данные сохраняются, переход на главный экран
---
## **B - Мой план**
### **US-B1. Создание программы тренировок**
1. Создание новой программы
   - Кнопка «Создать программу», поле названия (обязательное), выбор иконки/цвета
2. Добавление упражнений
   - Поиск по названию, фильтрация по группам мышц, список доступных упражнений
3. Настройка параметров
   - Подходы (1-10), повторения (1-50), вес (кг), заметки, сохранение параметров
4. Управление программой
   - Редактирование, удаление упражнений/программы (с подтверждением), дублирование, настройка перерывов
5. Отображение программы
   - Список упражнений (подходы × повторения × вес), количество упражнений, примерное время
### **US-B2. Расписание тренировок**
1. Просмотр календаря
   - Календарь месяц/неделя, отметки тренировок, цветовая индикация программ
2. Добавление тренировки
   - Выбор даты, программы, времени, повторение (разово/ежедневно/еженедельно/по дням)
3. Настройка повторений
   - Выбор дней недели, предпросмотр всех тренировок
4. Отображение расписания
   - Список на сегодня/завтра/неделю, уведомления, быстрый доступ к началу
5. Управление расписанием
   - Отмена (с вопросом о повторах), редактирование времени, замена тренировки
### **US-B3. Перенос тренировки**
1. Инициация переноса
   - Кнопка «Перенести» в карточке, доступна за 24ч до начала, недоступна для прошедших
2. Выбор новой даты/времени
   - Календарь, время, подсветка занятых слотов
3. Обработка конфликтов
   - Если время занято → предложить: перенести существующую / выбрать другое / заменить
4. Перенос повторяющихся
   - Выбор: только эту / все повторяющиеся, сохранение паттерна, предпросмотр изменений
5. Подтверждение
   - Отображение старой/новой даты, кнопка «Подтвердить», уведомление, обновление календаря
---
## **C - На тренировке**
### **US-C1. Экран выполнения**
1. Запуск тренировки
   - Кнопка «Начать» из расписания/программ, название программы, количество упражнений/подходов
2. Экран упражнения
   - Название, номер (например, «2 из 8»), описание
3. Чек-лист подходов
   - Целевые повторения/вес, чекбокс «Выполнено», поля для фактических значений (редактируемые)
4. Таймер отдыха
   - Автозапуск после подхода, обратный отсчет (30/60/90/120 сек), progress bar, звук/вибрация, кнопки «Пропустить»/«+30 сек»/«Пауза»
5. Навигация
   - Кнопки «Следующее»/«Предыдущее», прогресс-бар тренировки
6. Завершение
   - Кнопка «Завершить», подтверждение (если не все подходы), сохранение результатов
### **US-C2. Фиксация выполнения**
1. Отметка подхода
   - Чекбокс, автозапуск таймера, редактирование параметров, сохранение изменений
2. Пропуск
   - Кнопки «Пропустить подход»/«упражнение», таймер не запускается
3. Завершение тренировки
   - Кнопка доступна всегда, статистика (время, подходы, объем), поле для заметок
4. Сохранение результатов
   - Автосохранение, запись в историю, обновление статистики, уведомление питомцу
5. Редактирование
   - Возможность редактировать 24ч, история изменений, кнопка «Удалить» (с подтверждением)
### **US-C3. История тренировок**
1. Список тренировок
   - Хронологический (новые→старые), карточка: дата, программа, длительность, упражнения, статус
2. Фильтрация и сортировка
   - По программам, датам, сортировка по дате/длительности/объему
3. Детали тренировки
   - Полный список упражнений с подходами, веса, повторения, время отдыха, заметки
4. Статистика
   - Общее количество, средняя длительность, частота, прогресс по упражнениям
5. Экспорт
   - Кнопка «Экспортировать», форматы PDF/CSV, выбор периода

## **D - Мой питомец**
### **US-D1. Рост питомца**
1. Визуализация
   - Отображение на главном экране, индикация уровня/возраста
2. Прогресс роста
   - Уровни 1-50, XP за тренировку (+10 за завершенную, +5 за серию), прогресс-бар
3. Награды
   - Анимация получения опыта, сообщения от питомца («Я горжусь тобой!»)
4. Статистика
   - Уровень, опыт, количество тренировок, дней без пропусков, общее время
### **US-D2. Реакция на пропуски**
1. Отслеживание
   - Фиксация пропуска, подсчет дней с последней тренировки
2. Реакция питомца
   - 7 дней → грустит, 14+ дней → спит/не активен
3. Сообщения
   - 1 день: «Где мой человек? », 2 дня: «Скучаю... 😔», 3 дня: «Давай тренироваться! 💪», 5 дней: «Вернись! 😢», 7+: «Верю в тебя! ❤️🦊»
4. Push-уведомления
   - Напоминания на 2-й и 5-й день, персонализированные сообщения
5. Возвращение
   - Сообщение «Рад тебя видеть!», бонус XP
### **US-D3. Квесты и достижения**
1. Список квестов
   - На главном/отдельной вкладке, карточка: название, условие, прогресс, награда, срок
2. Типы квестов
   - Ежедневные («1 тренировка», «50 отжиманий»), еженедельные («3 тренировки», «новая программа»), достижения («Первая», «Неделя без пропусков», «3 подряд»)
3. Прогресс
   - Автообновление, progress bar, уведомление о завершении
4. Награды
   - XP для питомца, значки в профиль
5. История
   - Список достижений, дата получения

### **US-G1. Просмотр тарифов**
1. Экран тарифов
   - Доступ из меню/при попытке использовать pro, варианты Free/Pro, текущий выделен
2. Сравнение функций
   - Таблица с отметками ✓, категории: программы (Free: 2, Pro: безлимит), питомец, статистика (30 дней/вся), экспорт, ИИ, без рекламы

   - Цена Pro (месяц/год с выгодой)

1. Выбор периода
   - Месячная/годовая (экономия X%), выбранный подсвечен
2. Процесс оплаты
   - Шаг 1: подтверждение тарифа, Шаг 2: способ оплаты, Шаг 3: подтверждение (биометрия/пароль), индикатор загрузки

   - Недостаточно средств, ошибка сети, отмена → возврат на тарифы, повторная попытка

   - Статус, дата окончания, кнопка «Отменить», доступ до конца периода
